# IncaTechnologies Recurrence Radzen Components

This project implement an interface using [Radzen](https://blazor.radzen.com) components, to create, edit and visualize `IRecurrent` object from [IncaTechnologies.Recurrence](https://www.nuget.org/packages/IncaTechnologies.Recurrence) library.
